# 防晕车 · 视觉引导

一个纯前端、零依赖的极简网页，用随车辆真实运动漂移的视觉参考，帮助减轻乘车时的晕车不适。

在线访问：https://horizon-motion-8464.deed.page/

## 它解决什么问题

晕车的核心原因是感官冲突：眼睛看到的是相对静止的车内画面，内耳前庭却感受到加速、刹车与晃动。大脑收到两套不一致的信号，就容易引发不适。

这个页面让悬浮点、地平线和微粒场跟着设备的运动传感器一起漂移，给视觉系统提供它与身体感受一致的信号；同时用缓慢的呼吸环引导放松，帮助感官重新对齐。

## 主要功能

- **纯感应驱动**：只使用设备真实的运动/方向数据，不含模拟晃动。无传感器时会明确提示「设备不支持」或「未检测到传感器」，光点保持静止。
- **平滑跟随**：传感器数据经过低通滤波和弹性插值，光点漂移柔和，不会跳动。
- **自动校准**：开启后取前 12 帧数据求平均作为零点，也可以随时手动点「校准零点」重设。
- **横竖屏适配**：按屏幕旋转角度换算设备坐标系，横屏和倒置时方向依然正确。
- **呼吸引导**：6 秒一轮（吸气 3 秒、呼气 3 秒，每分钟 10 次），可开关。
- **控制项**：灵敏度滑杆、暂停/继续（空格键）、全屏；闲置 4 秒后控制栏与备案信息一起淡出，触碰或移动鼠标即恢复。
- **备案信息**：底部一行（手机端三行居中），含 ICP 与公安备案链接。

## 本地预览

直接打开 `index.html` 即可看到界面与呼吸引导；但运动传感器 API 需要安全上下文，所以要体验感应功能，请在目录下启动本地服务后用 `http://localhost` 访问：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。手机上使用时请通过 HTTPS 链接访问（见上方在线地址）。

## 使用建议

1. 在带加速度计/陀螺仪的手机浏览器中打开页面，点「开启感应引导」并授权运动与方向传感器。
2. 把手机固定在车内，或稳稳握住，避免手持抖动被误当成车辆运动。
3. 视线轻柔地落在中心光点上，跟随呼吸环自然呼吸。
4. 如果光点偏移方向或幅度不合适，点「校准零点」并重设灵敏度。

## 兼容性

- 安卓 Chrome、Edge、Opera、三星浏览器等普遍支持，一般无需授权弹窗；部分新版浏览器需要点击按钮授权。
- iOS Safari 需要在用户点击后通过 `requestPermission()` 授权运动与方向数据。
- 桌面浏览器通常没有传感器，页面会显示状态提示，仅保留呼吸引导。
